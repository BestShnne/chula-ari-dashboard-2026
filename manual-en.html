1. What is this system?

The Elderly Database System is a tool to survey, analyse and visualise data on older adults in the pilot areas of Pathumwan and Prawet districts. It helps community officers, volunteers, and researchers understand the elderly population across many dimensions — health, economy, society, technology, environment, and level of vulnerability.

The system is split into 3 main pages, switchable from the buttons at the top-right of every page:

📈
Overview
Key figures of the elderly population at a single glance
📊
Statistics
Drill into each dimension, compare groups, and cross-tabulate
🗺️
Map
See actual residence points on a map with per-household details

2. Getting started & shared components

The top bar (header) and some tools appear the same on every page, so you can browse data continuously.

Figure 1 — Top menu bar (switch 3 pages), district selector, and the "Show Unknown" toggle
A
Page switcher (top-right) — choose Overview / Map / Statistics at any time. Beside it, the 🌐 language button switches the whole interface between Thai and English.
B
District selector — pick "All districts", "Pathumwan" or "Prawet". It affects both the Statistics and Map pages.
C
"Show Unknown" toggle — turn on to include people who answered "Unknown / not specified" (shown in grey); turn off to hide them from all charts and tables.
💡 Tip
Turn off "Unknown" when you want to see proportions of only those who gave a clear answer — the percentages in the pie charts become easier to read.

3. Shared data filters: district · group · community

Both the Statistics and Map pages use the same hierarchical area selector:

Select district → Select group (cluster) → Select community
  • A group bundles several communities together by area (e.g. Charu Mueang group, On Nut group) — click a group chip to select/deselect; multiple groups can be selected.
  • A community is a sub-unit within a group. Once a group is selected you can drill into specific communities.
  • Selecting nothing = show combined data for the chosen district.

4. Overview page

The first page that opens. It summarises the structure of the elderly population on one screen — ideal for a quick, high-level presentation.

  • Sex and age group — horizontal proportion bars; hover to see the real figures.
  • Per-dimension cards — Health, Economy, Society, Technology, Environment; each shows a pie chart of a key topic in that dimension.
  • Dark pink = the "positive/has" value, light pink = the "negative/none" value, so you can read the direction instantly.
🎯 Worked example
"I want an overview of older adults in Prawet district — which sex is the majority, which age group they fall in, and what proportion live alone."
Answer — click in this order
  1. Click "Overview" at the top-right.
  2. In the district selector choose "Prawet".
  3. Read the "Sex" and "Age group" bars at the top — hover each bar for the exact count/percentage.
  4. Scroll to the "Society" dimension card and read the pie chart on living arrangement / living alone.

5. Map page

Shows the actual residence points of older adults on a map. The size and colour of each dot reflect the number of people and the area group — ideal for planning field visits.

Figure 2 — Summary cards on top + points on the map
Figure 3 — Info card shown when a point is clicked
  • Summary cards on top — elderly shown, residence points, number of communities, and average age.
  • Click a point to open the per-household card showing ID · sex · age · ADL · chronic disease and the household's vulnerability level.
  • 📄 Export this house as PDF — creates a document for the selected household only.
  • 🧭 Directions — opens Google Maps routing to the household's coordinates (in a new browser tab).
  • Filter map points — pick a dimension / sub-topic / value to show only people who match, e.g. only those with a fall history or high vulnerability.
🎯 Worked example
"I need to find elderly households with a fall history in the Charu Mueang group to plan visits and navigate to their homes."
Answer — click in this order
  1. Click "Map" at the top-right.
  2. Choose district selector → "Pathumwan", then click the group chip "Charu Mueang".
  3. In the map filter pick dimension "Health" → sub-topic "Fall history" → value "Has fallen".
  4. The map now shows only matching households — click a point to see ID · ADL · vulnerability level.
  5. Click 🧭 Directions to open the route, or 📄 Export this house as PDF to keep as a field document.
⚠️ Note
If the base map does not appear (grey background), it is usually a network blocking the map tiles (OpenStreetMap). Open on a normal network or refresh. The data points and clicking still work as usual.

6. Statistics page

The page for drilling in and comparing. It works as 4 steps from top to bottom.

Figure 4 — Select dimension → sub-topic → break down (cross-tab) → data type
1
Select dimensions of interest — pick several (Health, Economy, etc.) or "All dimensions". There is a "⚠️ Vulnerability Index" tab next to the All button. If no dimension is selected, no sub-topics are shown.
2
Select sub-topics — choose the questions/indicators to display, ordered by the dimensions above. Each sub-topic renders as its own chart or table.
3
Break down by (cross-tab) — pick one variable at a time to cross-tabulate, e.g. view "Smartphone use" split by "Age group". Rows are the breakdown groups; columns are the sub-topic values.
4
Select data type — switch the display between Table, Bar chart or Pie chart as you like.
🎯 Worked example
"I want to know how smartphone use among older adults in Pathumwan differs by age group, then use the result in a report."
Answer — click in this order
  1. Click "Statistics" at the top-right, then choose district selector → "Pathumwan".
  2. Step 1: select dimension "Technology".
  3. Step 2: select sub-topic "Smartphone use".
  4. Step 3: under "Break down by" choose "Age group".
  5. Step 4: choose data type "Bar chart" to compare each age group easily.
  6. Click "Charts summary CSV" (or PDF) to take the table into analysis / a report.
💡 Tip
Use cross-tab together with multiple group selection to find spatial differences, e.g. comparing vulnerability levels between communities. Then click "Clear filters" to start over instantly.

7. Filters & the filter summary

Whenever you set filters, the system shows a filter summary so you can see exactly which slice of data you are viewing. It appears both on screen (above the charts/cards) and in exported files.

🔎 Example: Filters applied: District: Pathumwan · Group: Charu Mueang · Community: Trok Salak Hin · Sex: Female, Male · Showing "Unknown"
  • Selecting several values within the same topic separates them with "," (e.g. Female, Male), meaning "both" — not "either/or".
  • The Clear filters button resets everything to the defaults.

8. Exporting to PDF & CSV

Both the Statistics and Map pages have export buttons. Every file attaches the filter summary and the date/time the report was generated for reference.

📄 Export PDF
A print/share-ready report with the charts, tables or map as currently shown — good for presenting and keeping as a record.
📊 Export CSV
Raw data as a table; open it in Excel / Google Sheets for further analysis.

9. Tips & FAQ

❓ I selected a group but see no communities?
You must select a "group" first; the "community" options within that group only appear afterwards.
❓ The chart numbers aren't what I expected?
Check the "Show Unknown" toggle and the filter summary at the top to see which district/group/community is being filtered.
❓ Can I compare several areas at once?
On the Statistics page, select several groups at once; each group appears as its own colour series in the same chart/table.
❓ Directions button shows "blocked"?
This only happens inside an editor/preview that restricts Google connections. On the live page it navigates normally.

10. Glossary

Term Meaning

Sub-topicAn indicator/question within a dimension that is displayed.
Cluster (group)A bundle of several communities grouped by area.
CommunityA sub-area unit within a group.
Cross-tabSplitting a sub-topic by another variable to see the relationship.

Vulnerability levelAn index summarising an older adult's risk/vulnerability (low · moderate · high · very high).
